# SOARM101 ROS2 Workspace

Репозиторий содержит полный программный стек для взаимодействия с роботизированной рукой **SOARM101** в среде ROS2 Humble. Решение построено на базе фреймворка `ros2_control`, поддерживает аппаратное управление сервоприводами, интеграцию с MoveIt2 и предоставляет удобные интерфейсы для телеметрии и калибровки.

> **Документация двухуровневая**:  
> - Здесь — общее описание workspace, инструкция по развёртыванию и связи между пакетами.  
> - В каждом пакете — собственная подробная документация (архитектура, API, примеры использования).

## Структура репозитория

| Пакет | Назначение |
|-------|------------|
| **`soarm101_bringup`** | Пакет-агрегатор, запускающий всю систему (узлы, контроллеры, MoveIt). |
| **`soarm101_description`** | URDF-описание робота, геометрия, кинематика, визуализация. |
| **`soarm101_hardware`** | Компонент аппаратного интерфейса для `ros2_control` (управление сервоприводами через SDK). |
| **`soarm101_ros2_control`** | Конфигурационные файлы `ros2_control` (контроллеры, интерфейсы, параметры). |
| **`soarm101_telemetry_controller`** | Кастомный контроллер для чтения и публикации телеметрии (положения, усилия, температура). |
| **`soarm101_moveit_config`** | Конфигурация MoveIt2 для планирования траекторий. |
| **`soarm101_interfaces`** | Кастомные сообщения и сервисы для обмена данными с роботом (в удобном формате). |
| **`soarm101_nodes`** | Примеры узлов для взаимодействия с роботом (демонстрационные скрипты). |
| **`converter_calibration_data`** | Инструмент для конвертации калибровочных данных из формата `lerobot` в кастомный формат workspace. |
| **`scservo_sdk`** | SDK для работы с сервоприводами SC‑SERVO (используется `hardware`‑компонентом). |

Подробное описание зависимостей между пакетами см. в `package.xml` каждого пакета.

## Требования к системе

- **Операционная система**: Ubuntu 22.04 (рекомендуется)  
- **ROS2**: Humble (протестировано на Humble)  
- **Компилятор**: C++17, Python 3.8+  
- **Аппаратное обеспечение**: роборука SOARM101 (подключённая по USB/последовательному порту)  
- **Дополнительно**:  
  - Установленный `lerobot` (для калибровки) – см. [lerobot/lerobot](https://github.com/lerobot/lerobot)  
  - Для работы с MoveIt2: `moveit2`, `moveit_visual_tools` и др. (будут добавлены в зависимости позже)

## Процесс развёртывания и запуска

1. **Установите lerobot** (следуйте инструкциям официального репозитория) и проведите калибровку робота согласно документации lerobot.  
2. **Включите робота** и подключите к компьютеру.  
3. **Преобразуйте калибровочные данные** в нужный формат:  
   ```
   cd converter_calibration_data
   python3 convert.py --input <lerobot_calib_file> --output <custom_file>
   ```  
   (подробнее см. документацию пакета `converter_calibration_data`).  
4. **Соберите workspace** (из корня репозитория):  
   ```
   colcon build --symlink-install
   ```  
5. **Запустите полный стек** через bringup:  
   ```
   source install/setup.bash
   ros2 launch soarm101_bringup soarm101.launch.py
   ```

## Внешние интерфейсы стека (Public API)

После запуска системы внешние пользователи и узлы могут взаимодействовать с роботом через следующие ROS2-интерфейсы:

**Топики (Topics):**
- `/joint_states` (`sensor_msgs/msg/JointState`) — текущие положения, скорости и усилия всех сочленений (публикуется стандартным контроллером).
- `/soarm101_telemetry_controller/motor_states` (`soarm101_interfaces/msg/MotorStates`) — расширенные данные телеметрии: температура сервоприводов, напряжение, флаги ошибок (публикуется кастомным телеметрийным контроллером).
- `/tf` — трансформации между звеньями робота (для визуализации в RViz и навигации).

**Действия (Actions):**
- `/follow_joint_trajectory` (стандартный action из `control_msgs`) — основной интерфейс MoveIt2 для выполнения спланированных траекторий.

> **Примечание:** точные названия сервисов и полей сообщений зависят от реализации. Для детального описания форматов обращайтесь к документации пакета `soarm101_interfaces`.
