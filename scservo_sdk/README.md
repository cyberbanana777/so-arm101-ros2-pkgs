# scservo_sdk

Пакет предоставляет низкоуровневый SDK для управления сервоприводами **Feetech** серий SCSCL, SMS_STS, HLSCL и SCS0009 через последовательный порт. Используется в составе стека SOARM101 для аппаратного управления роборукой.

---

## Состав пакета

Пакет собирается как **статическая библиотека** (`libscservo_sdk.a`) и содержит следующие классы:

- **`SCSerial`** – работа с последовательным портом (POSIX, Linux).
- **`SCS`** – базовый протокол обмена (пакеты, контрольная сумма, синхронные операции).
- **`SMS_STS`** – управление сервоприводами SMS/STS (режимы: серво, замкнутое колесо, разомкнутое колесо).
- **`SCSCL`** – управление сервоприводами SCSCL (позиция, ШИМ).
- **`HLSCL`** – управление сервоприводами HLS (позиция, скорость, усилие).
- **`SCS0009`** – управление сервоприводами SCS0009 (используются, например, в руке AmazingHand).

**Вспомогательные модули:**
- `ServoUtils` – кодирование/декодирование знаковых значений с битом направления.
- `SyncWriteBuffer` – RAII‑буфер для синхронной записи.
- `ServoErrors` – стандартизированные коды ошибок.

## Использование в других пакетах

### В `package.xml` (зависимость)

```xml
<depend>scservo_sdk</depend>
```

### В `CMakeLists.txt`

```cmake
find_package(scservo_sdk REQUIRED)

target_link_libraries(your_node
  scservo_sdk
)
```

Подключение заголовочных файлов:

```cpp
#include "SCServo.h"
```

### Пример инициализации и управления мотором (SMS_STS)

```cpp
#include "SCServo.h"

SMS_STS servo;
servo.begin(1000000, "/dev/ttyUSB0");  // 1 Мбит/с, порт
servo.InitMotor(1, 0, 1);              // ID=1, режим серво, включить усилие
servo.WritePosEx(1, 2048, 1000, 50);   // переместить в центр
```

## Зависимости

- ROS2 Humble (только для сборки, пакет не использует ROS‑интерфейсы).
- POSIX-система (Linux) с поддержкой `termios`.
- Стандартная библиотека C++17.
