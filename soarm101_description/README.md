# soarm101_description

Пакет содержит геометрическое описание (URDF) роботизированной руки **SOARM101**, а также 3D-модели (STL) для визуализации и расчёта коллизий. Описание выполнено в формате **xacro** для гибкой настройки параметров (например, симуляция/реальное железо).

---

## Состав пакета

- **`urdf/soarm101.xacro`** – основной файл описания робота (xacro). Определяет:
  - кинематическую цепь (7 сочленений: shoulder_pan, shoulder_lift, elbow_flex, wrist_flex, wrist_roll, gripper_jaw, а также фиксированное соединение world–base),
  - инерционные характеристики каждого звена,
  - визуальные и коллизионные геометрии (ссылки на STL‑меши),
  - пределы усилий, скоростей и диапазоны движения для каждого сустава.

- **`meshes/`** – содержит STL-файлы для каждого звена и компонента:
  - базовые держатели, корпуса моторов, плечи, предплечье, запястье, схват и т.д.
  - Все меши используются как для визуализации, так и для коллизий.

## Использование в других пакетах

Пакет не содержит исполняемых узлов, только описательные файлы. Для загрузки модели робота в ROS2 используйте стандартные средства:

### В launch-файлах (например, в `soarm101_bringup`):

```python
from launch_ros.parameter_descriptions import ParameterValue
from launch.substitutions import Command

robot_description = ParameterValue(
    Command(['xacro ', find_package('soarm101_description'), '/urdf/soarm101.xacro']),
    value_type=str
)
```

### В C++ / Python узлах для получения URDF:

```cpp
#include <urdf/model.h>
urdf::Model model;
model.initParam("robot_description");
```

### В RViz / MoveIt

Пакет автоматически устанавливает файлы в `share/soarm101_description/`, поэтому пути к мешам внутри URDF используют `package://soarm101_description/meshes/...`, что корректно разрешается в ROS2.

---

## Аргументы xacro

- **`use_sim`** – по умолчанию `true`. Определяет, использовать ли симуляционные параметры (например, для Gazebo). При необходимости можно переопределить в launch-файле.

---

## Зависимости

- `urdf` – для парсинга URDF,
- `xacro` – для обработки xacro-файлов.

---

## Происхождение

Исходный URDF-файл взят из официального репозитория [TheRobotStudio/SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100) (файл `Simulation/SO101/so101_new_calib.urdf`).  
Внесены следующие изменения:
- адаптация под наш стек (добавлены инерции, уточнены позиции и ориентации),
- переход на xacro для удобства параметризации,
- приведены в соответствие имена суставов и звеньев для интеграции с `ros2_control` и `soarm101_hardware`.
